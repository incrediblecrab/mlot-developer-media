# mlot-developer-media

This repository stores the animated GIFs used by Max's Lab of Things README files and product pages. It is a public asset host, not an application; other repositories embed these files through stable `raw.githubusercontent.com` URLs, so file names and paths are part of the interface.

**Objective:** keep reusable developer-media assets in one repository so project READMEs can reference a stable public URL without duplicating binary files.

**Inputs:** exported GIF demonstrations for VS Code extensions and npm packages. The repository has no build step.

**Files:**

- [`gifs/`](gifs/): animated demonstrations for developer tools and extensions

## Folder layout

`gifs/` contains the published demonstration GIFs. Do not move or rename files in this folder without updating every README or site that embeds the corresponding raw GitHub URL.
